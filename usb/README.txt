============================================================
 교육사진 자동 숏폼 만들기 - USB 사용법
============================================================

[ 처음 한 번만 ]

 1. 이 폴더 전체를 USB 에 복사하세요.

    ** 폴더 경로를 짧고 단순하게 만드세요 **

      좋은 예)  G:\shorts
      나쁜 예)  G:\[안전폴더]\utube-jadonghwa--claude-...\utube-jadonghwa--...

    대괄호 [ ] 가 들어가거나 경로가 길면 설치가 실패합니다.
    윈도우가 그런 경로를 제대로 다루지 못합니다.
    압축을 풀면 폴더가 두 겹으로 들어가는 경우가 많으니,
    안쪽 폴더만 꺼내서 G:\shorts 로 이름을 바꾸세요.

 2. usb 폴더 안의  setup.bat  을 더블클릭하세요.
 3. 10~30분 기다리면 설치가 끝납니다. 창을 닫지 마세요.

 인터넷이 되는 곳에서 설치하세요. 설치가 끝나면 인터넷 없이도 씁니다.
 (자동 자막 기능만 인터넷이 필요합니다)


[ 영상 만들기 - 두 가지 방법 ]

 방법 1. 한 편씩 만들기
   - watch 폴더 안에 활동 이름으로 폴더를 만들고 사진을 넣으세요
   - make_one.bat 을 더블클릭하고 안내를 따르세요

 방법 2. 자동으로 만들기
   - watch_start.bat 을 더블클릭해 켜 두세요
   - watch 폴더에 사진을 넣으면 3분 뒤 알아서 만들어집니다
   - 끌 때는 그 창에서 Ctrl 키와 C 키를 함께 누르세요

 무엇이 만들어질지 미리 보려면  check_only.bat  을 누르세요.


[ 폴더 구조 ]

   watch\
     과학실험\
       1.jpg
       2.jpg
       description.txt   <- 선택. 활동 설명 한 줄. 없으면 폴더 이름을 씁니다
     운동회\
       ...

   output\
     과학실험.mp4          <- 완성된 영상
     과학실험_work\
       review_sheet.jpg    <- 검수용. 꼭 보세요


[ 업로드 전에 반드시 ]

 output 폴더의 review_sheet.jpg 를 여세요.
 초록 상자가 실제로 가려진 얼굴입니다.

 얼굴 감지는 100% 가 아닙니다. 실제 교실 사진에서 45명 중 43명을 찾았습니다.
 상자가 없는 얼굴이 있으면 그 사진을 빼거나 직접 가린 뒤 다시 만드세요.

 학생 사진은 개인정보입니다. 보호자 동의와 학교 보안정책을 먼저 확인하세요.


[ 잘 안 될 때 ]

 setup_log.txt 파일에 무슨 일이 있었는지 다 적혀 있습니다.
 그 파일과 화면에 뜬 메시지를 함께 보내주시면 고쳐 드립니다.

 자주 있는 경우
  - 경로 관련 실패    : 폴더를 G:\shorts 로 옮기고 다시 실행하세요
  - "설치 완료" 인데
    전부 못 불러옴    : python 폴더의 python311._pth 파일을 메모장으로 열고
                       아래 다섯 줄로 바꾼 뒤 저장, setup.bat 다시 실행

                         python311.zip
                         .
                         Lib\site-packages
                         ..
                         import site
  - "다운로드 실패"   : 학교 방화벽 문제일 수 있습니다. 다른 네트워크에서 해 보세요
  - "공간 부족"       : USB 에 2GB 이상 남겨 두세요
  - "DLL" 오류        : 'Visual C++ Redistributable x64' 를 설치하세요
  - 한글이 깨져 보임   : 영상에는 문제 없습니다. 검은 창 표시만 그렇습니다
